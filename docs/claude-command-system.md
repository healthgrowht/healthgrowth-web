# Claude Command System — Biblioteca de Comandos Health Growth
Versión: 1.0 | Fecha: 2026-06-22

---

## Propósito

Comandos reutilizables para trabajar rápido con Claude Code en el ecosistema HG.
Cada comando tiene un objetivo preciso y ejemplos aplicados al negocio real.

---

## MODOS DE TRABAJO MAESTROS

### ARCHITECT
**Para qué**: Diseñar la estructura antes de construir.
**Cuándo usarlo**: Al iniciar un módulo nuevo, sistema o automatización.
**HG**: "ARCHITECT el sistema de seguimiento de leads días 3 y 7"
**Patitas**: "ARCHITECT el flujo de ROKITO para manejo de cancelaciones"

### AUTOMATE
**Para qué**: Identificar y eliminar trabajo manual repetitivo.
**Cuándo usarlo**: Cuando algo se hace 3+ veces igual.
**HG**: "AUTOMATE el proceso de registro de leads desde formulario web"
**Patitas**: "AUTOMATE la confirmación de reservas que hace Alicia manualmente"

### OPERATOR
**Para qué**: Ejecutar una secuencia de operaciones en orden.
**Cuándo usarlo**: Para procesos multi-paso que siguen siempre el mismo orden.
**HG**: "OPERATOR: publicar contenido semana → actualizar CRM → revisar métricas"
**Patitas**: "OPERATOR: recibir DM → capturar datos → notificar Alicia → confirmar"

### SENTINEL
**Para qué**: Revisar riesgos y puntos de falla antes de ejecutar.
**Cuándo usarlo**: Antes de deploy, antes de contactar clientes reales, antes de pagar.
**HG**: "SENTINEL: revisar webhook n8n antes de activar en producción"
**Patitas**: "SENTINEL: revisar ROKITO antes de activar en Instagram real"

### CEOMODE / FOUNDER
**Para qué**: Tomar decisiones desde la perspectiva del dueño del negocio.
**Cuándo usarlo**: Para priorizar, evaluar estrategia, decidir inversiones.
**HG**: "CEOMODE: ¿deberío contactar estos 3 prospectos esta semana o la siguiente?"
**Patitas**: "FOUNDER: ¿vale la pena activar WhatsApp Business ahora o esperar?"

## ESCRITURA Y ESTILO

### /punch
**Para qué**: Hacer que un texto sea más directo y con más impacto.
**HG**: "/punch este caption de Instagram sobre dolor pyme"
**Patitas**: "/punch este mensaje de bienvenida de ROKITO"

### /flow
**Para qué**: Mejorar la fluidez y lecturabilidad de un texto.
**HG**: "/flow este diagnóstico antes de enviarlo al cliente"

### /trim
**Para qué**: Eliminar todo lo que sobre sin perder el mensaje.
**HG**: "/trim esta propuesta comercial. Que quede en máximo 5 páginas."

### /hook
**Para qué**: Generar la primera línea perfecta para captar atención.
**HG**: "/hook para un reel sobre pymes que pierden clientes por WhatsApp"
**Patitas**: "/hook para presentar el caso de transformación de Patitas Felices"

### /polish
**Para qué**: Última revisión antes de publicar o enviar.
**HG**: "/polish esta propuesta para Inmigrants Barber Studio"

## ESTRATEGIA

### /redteam
**Para qué**: Buscar fallas en un plan antes de ejecutarlo.
**HG**: "/redteam el plan de activación de CHIMI en Instagram"
**Patitas**: "/redteam el flujo de ROKITO — qué puede fallar"

### PARETO
**Para qué**: Identificar el 20% de acciones que generan el 80% de resultados.
**HG**: "PARETO: ¿qué 3 cosas debo hacer esta semana para acercarme a mi primer cliente HG?"

### BOTTLENECK
**Para qué**: Identificar el cuello de botella que frena el sistema.
**HG**: "BOTTLENECK: ¿por qué el pipeline de leads no avanza más rápido?"

### LEVERAGE
**Para qué**: Identificar puntos de apalancamiento de alto impacto.
**HG**: "LEVERAGE: ¿qué única acción esta semana produce más leads?"

### /premortem
**Para qué**: Imaginar que el proyecto falló y entender por qué.
**HG**: "/premortem: Health Growth no captó clientes en 3 meses — ¿qué pasó?"
