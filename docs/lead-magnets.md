## Propósito

Recursos gratuitos de alto valor que:
1. Atraen a la pyme correcta
2. Demuestran autoridad de HG antes de vender
3. Capturan datos de contacto
4. Inician la conversación de ventas

**Regla**: Cada lead magnet tiene un CTA claro al final.

## Cómo Distribuir los Lead Magnets

| Canal | Cómo entregarlo |
|-------|----------------|
| Instagram comentarios | Respuesta automática con ManyChat → DM |
| Instagram DM directo | Texto + link o PDF adjunto |
| Formulario web | Después de completar → entrega automática |
| WhatsApp | Mensaje manual o automático (CHIMI) |
| Email | Si se tiene el email del lead |

---

## Formato de Entrega por Instagram

```
Comentario "CHECKLIST" en cualquier post →
  → ManyChat detecta palabra clave
  → Envía DM automático con el recurso
  → Pregunta: "¿De qué tipo es tu negocio?"
  → Inicia secuencia de calificación
```
