## 10 ESTRUCTURAS DE ESCENAS

### ESTRUCTURA A — Hook → Dolor → Solución → CTA
1. Hook fuerte (problema en una línea)
2. Ampliar el dolor (3 ejemplos o señales)
3. Solución presentada (Health Growth)
4. CTA claro

### ESTRUCTURA B — Antes/Después
1. "Antes": estado actual del problema
2. Transición visual
3. "Después": estado mejorado
4. "¿Cómo llegar de A a B? Nosotros."

### ESTRUCTURA C — Personaje (Chimi)
1. Chimi aparece
2. Chimi hace preguntas o detecta problema
3. Chimi da veredicto
4. Chimi recomienda acción

### ESTRUCTURA D — Número y Lista
1. "X cosas que [problema]"
2. Ítem 1, 2, 3... aparecen uno a uno
3. Resumen
4. CTA

### ESTRUCTURA E — Historia
1. Contexto personal (Carlos o Alicia)
2. El problema que vieron
3. La solución que construyeron
4. Invitación a unirse

### ESTRUCTURA F — Tutorial Rápido
1. "Haz esto en 5 minutos"
2. Paso 1, 2, 3
3. Resultado esperado
4. CTA para ir más lejos

### ESTRUCTURA G — Social Proof
1. Presentar caso (Patitas Felices)
2. Situación inicial
3. Resultado actual
4. "¿Tu negocio puede ser el siguiente?"

### ESTRUCTURA H — Objeción → Respuesta
1. "Muchos dicen: [objeción común]"
2. "La realidad es:"
3. Respuesta directa con dato o ejemplo
4. CTA

### ESTRUCTURA I — Pregunta Directa
1. Pregunta potente al espectador
2. Silencio / pausa visual
3. Respuesta + explicación
4. CTA

### ESTRUCTURA J — Objeto Parlante
1. Introducción del objeto
2. El objeto habla de su problema
3. La solución aparece
4. CTA del negocio
